    bc: Exercise large and tiny square roots in native benchmarks
    
    A first-per-group subset measured only the small sqrt winner and could
    miss changes to large precision or fractional initial estimates. Append
    scale-10000, tiny-fraction and large-integer classes with exact independent
    oracles; retain scale 5000 and both tiny dimensions in native checks.
    
    Preserve all 46 prior complete case dictionaries across full, held-out
    and quick presets with committed source-anchored hashes. Report actual
    even tiny-square dimensions rather than relabeling preset inputs.
    
    All 23 harness tests pass on Python 3.9 and 3.15, including the actual
    50-case quick corpus with the baseline executable. Six native-policy
    orchestration tests pass. The missing-case check fails before the change.
    
    Refs #216, #212 and #197.
